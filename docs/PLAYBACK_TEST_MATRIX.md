# V1 播放闭环测试矩阵

## 自动检查

- Debug HAP 构建必须成功且无 ArkTS 编译错误。
- Release 构建开启混淆后必须成功。
- URL 解析器覆盖空值、超长、错误协议、无主机、内嵌凭据和合法直链。
- 播放状态覆盖 prepare、play、pause、buffering、completed、error 和 release。

## 媒体样本

测试媒体必须来自自有或明确授权的固定服务器，测试记录不保存含签名参数的完整 URL。

| 类型 | 必测组合 |
| --- | --- |
| MP4 | H.264/AAC、H.265/AAC、可跳转、无 moov 前置优化 |
| MKV | H.264、H.265、多音轨、内挂字幕 |
| MPEG-TS | 点播 TS、连续时间戳、异常时间戳 |
| HLS | VOD、Live、Master Playlist、多码率、AES 合法授权样本 |
| Audio | MP3、AAC、FLAC、WAV、OGG |
| 异常 | 404、403、超时、无 Range、错误 MIME、截断文件、无效证书 |

## 操作场景

- 首次打开后自动起播，首帧出现前显示加载状态。
- 播放、暂停各连续操作 20 次，状态与按钮一致。
- 拖动到开头、中间、结尾，进度不会回跳到旧位置。
- 播放完成后可重新播放。
- 缓冲开始和结束时 UI 正确恢复到播放或暂停状态。
- 失败后点击重试不会残留旧播放器事件。
- 连续返回并重新打开 50 次，无崩溃、黑屏累积或音频残留。
- 播放中断网、恢复网络、Wi-Fi 切换和服务器主动断开。
- 前后台切换、锁屏、旋转、分屏和应用被系统回收。

## 性能与资源

- 记录 URL 提交到首帧的 P50、P95。
- 连续播放 2 小时，检查内存、CPU、温升、耗电和音画同步。
- 连续换源 50 次后内存回到稳定水位。
- 页面退出后播放器实例、Surface、网络连接和音频焦点全部释放。
- 网络文件协议点击后立即进入播放器，下载未完成时可出现首帧；SMB、SFTP、FTP、NFS 的缓存文件持续增长且不会被播放器提前判定为完整文件。
- 限速或暂停协议服务时，播放器进入缓冲并在缓存继续增长后恢复；协议认证、读取或本地缓存失败时显示统一播放错误。
