# 横竖屏默认全屏修正与验证 — 2026-10-16

## 结果和范围

用户更正：横屏、竖屏都默认全屏；不需要单独进入/退出全屏的按钮。本轮据此替代上一轮普通滚动页面布局，保留跟随系统、锁定横屏、锁定竖屏，不强行旋转视频画面。

基础提交：`8bf5d73552d462cb397f752c85c52070018c554e`。候选分支：`codex/linkora-player-default-immersive-v1`，未合入生产分支。旧报告记录当时行为，不修改旧验收结果。

## 原因与改动

- 上一版把视频放在页面 Scroll 内，并限制为滚动视口高度的 60%，横屏时实际画面明显缩小。现移除固定 16:9 容器、60% 高度上限以及视频外层滚动布局。
- 画布始终为整个播放窗口的宽高；系统播放器与 MPV 共用这一布局，实际画面仍由原生适应/裁剪/拉伸策略处理。默认适应保留比例，横向视频在竖屏有上下黑边，超宽窗口可能有左右黑边；没有强制裁剪或拉伸。
- 标题、方向选择和可滚动播放控制叠加于画布，单击画面隐藏或唤出；进入时控制栏可见。控制区滚动不改变视频窗口尺寸，不提供全屏开关，也没有新增自动隐藏计时器。
- 进入播放时隐藏状态/导航栏，方向切换不退出全屏。窗口 owner 继续串行处理原生操作；离开后恢复原方向及普通应用的状态/导航栏，即使方向恢复失败也执行系统栏恢复。
- 复核修正两项覆盖问题：覆盖层空白区允许视频手势穿透；播放 ERROR 时不显示控制覆盖层，防止挡住错误恢复按钮。错误页“编辑来源”使用受保护的关闭流程。
