# 网络存储版本计划

## 版本边界

网络存储能力属于 V2，不与 V1 流媒体直链版本捆绑发布。两个版本共享播放内核、媒体格式识别、字幕、播放历史和安全存储，但数据入口完全分开：

- V1：用户粘贴 HTTP/HTTPS/HLS/DASH 媒体地址后直接播放。
- V2：用户扫描或手动添加服务器，登录后浏览目录并选择文件播放。

V1 的发布不依赖 V2 协议完成；V2 在 V1 播放内核稳定后开发。

当前 UI 已分为独立的“串流”和“网络”一级导航。串流暂复用 `network_server` 中的 HTTP 记录，不迁移数据库；两页加载、添加、编辑和删除后分别筛选 HTTP 与存储协议，避免旧链接或写入结果混入服务器列表。串流列表加载不探测链接，用户主动测试时才执行连接检查与 API 20 `AVMetadataExtractor.setUrlSource` 媒体信息提取；提取失败不阻止保存或播放，HLS/DASH 的时长和分辨率在播放时读取。页面离开、地址修改或关闭表单会取消检查，提取器最长保留 8 秒并释放。代理封装仍待后续实现。

## 协议范围

| 协议 | 首发范围 | 默认端口 | 实现路径 | 安全策略 |
| --- | --- | ---: | --- | --- |
| WebDAV | 目录、属性、Range 读取 | 443 | ArkTS HTTP | 默认 HTTPS，HTTP 需明确确认 |
| SMB | SMB 2/3，共享与目录浏览 | 445 | HarmonyOS NDK 适配器 | 禁用 SMB1；优先签名/加密 |
| SFTP | 密码、密钥登录与随机读取 | 22 | HarmonyOS NDK 适配器 | 首次连接确认主机指纹，变更后阻断 |
| FTP | 目录与被动模式读取 | 21 | HarmonyOS NDK 适配器 | 优先 FTPS；明文 FTP 明示风险 |
| NFS | 只读目录与随机读取 | 2049 | HarmonyOS NDK 适配器 | V2 首发只读；禁止自动写入或挂载 |

Native 三方库必须使用 HarmonyOS NDK 重新编译，按 arm64-v8a 和 x86_64 管理产物；每个依赖在选型前完成许可证、维护状态、CVE 和线程模型评审。

## 统一数据通路

所有协议实现同一个随机读取接口：

```text
RemoteFileReader
  ├─ stat() -> size / modifiedTime / seekable
  ├─ read(offset, length) -> bytes
  ├─ cancel()
  └─ close()
          │
          ▼
bounded sparse cache
          │
          ▼
AVDataSrcDescriptor.callback
          │
          ▼
AVPlayer
```

播放器不感知 SMB、SFTP、FTP 或 NFS。协议适配器负责认证、重连和随机读取；缓存层负责预读、请求合并、并发上限和淘汰。关闭播放会话时，取消读取、清空内存缓存并释放连接。

## 网络扫描

扫描必须由用户主动触发，只扫描当前局域网，并提供取消和超时。扫描结果只表示“发现服务”，不会自动登录或尝试默认密码。

### 被动/标准发现

- mDNS / DNS-SD：发现 WebDAV、SFTP、FTP 及主动广播的 NAS 服务。
- WS-Discovery：发现支持该标准的 SMB/NAS 设备。
- NetBIOS Name Service：兼容未发布 mDNS 的旧式 SMB 设备。
- SSDP：补充发现 NAS、媒体服务器和网关设备，但不把 UPnP 媒体能力混入文件协议。
- rpcbind：发现明确暴露 NFS 服务的设备。

### 定向探测

只有标准发现没有结果且用户继续操作时，才对当前子网做限速的目标端口探测。探测范围仅包括 21、22、80/443、111、445、2049 等已支持服务端口；必须限制并发、总时长和重试次数，不进行漏洞识别，不跨越当前路由网段。

### 结果合并

同一设备可能被多种机制发现。以 IP/主机名、服务类型、端口和稳定服务标识进行去重，展示设备名、地址、可用协议和安全状态。MAC、SSID、网络拓扑与服务器名称不得进入远程日志或埋点。

## 凭据与证书

- 连接配置和凭据分表保存，业务数据库只存 `credentialRef`。
- 密码、私钥口令、Cookie 和 Token 使用系统关键资产或 HUKS 能力。
- SSH 私钥不得导出；服务器指纹单独固定并支持用户主动更新。
- TLS 证书错误默认阻断，不能提供“一直忽略所有证书”开关。
- 删除服务器时同步删除凭据、指纹、缓存与播放历史关联。
- 日志只记录协议、匿名 source id、阶段和错误码。

## 开发顺序

1. V2.0-alpha1：连接配置模型、凭据引用、WebDAV 浏览和读取。
2. V2.0-alpha2：mDNS/DNS-SD 扫描、结果去重和手动添加。
3. V2.0-beta1：SMB 2/3 与 WS-Discovery/NetBIOS。
4. V2.0-beta2：SFTP、SSH 指纹和密钥登录。
5. V2.0-rc1：FTP/FTPS、NFS 只读、定向探测和全协议回归。
6. V2.0：安全审计、协议许可证审计、弱网/大文件/长稳测试完成后发布。

## V2 发布门槛

- 五种协议分别通过 NAS、Windows、Linux 和常见自建服务端兼容矩阵。
- 目录含 10 万项时可分页/增量展示，UI 不阻塞。
- 4K 大文件随机跳转、连续换片、休眠恢复和断线重连稳定。
- 扫描可在 15 秒内取消，后台不持续扫描。
- 错误提示区分网络、认证、权限、证书/指纹、路径和媒体格式。
- 明文协议和不安全配置在连接前有清晰风险提示。
