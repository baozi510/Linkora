# 产品与交付计划

## 产品定位

Linkora 只播放用户主动添加、且用户有权访问的媒体资源，不提供内容搜索、聚合源或破解能力。第一发布目标是手机和平板，核心体验对齐成熟网络播放器的“添加地址—识别资源—稳定播放—记住进度”链路。

## 版本范围

产品按同一应用的两个大版本推进，V1 是流媒体直链播放器，V2 是网络存储播放器。V2 不阻塞 V1 上架。

### V1.0：流媒体直链版本

#### P0：工程与链接入口（已完成）

- 可由 DevEco Studio 打开和构建的原生工程
- URL 规范化、协议白名单、长度限制、凭据拦截
- 根据路径推断常见流媒体与封装格式
- 首屏链接输入与错误反馈
- 发布、隐私、安全和质量基线文档

验收：Debug HAP 可构建；非法输入不崩溃；输入内容不被上传、不写日志。

#### P1：可播放闭环

- `AVPlayer` 状态机封装，所有事件在设置资源前注册
- `XComponent` Surface 生命周期管理
- HLS、HTTP(S) 直链播放；播放、暂停、跳转、倍速、音量
- 系统文件选择器、本地授权 URI 与 `fdSrc` 播放
- 加载、缓冲、首帧、失败与重试状态
- 退出页面时 reset / release，避免解码器与内存泄漏
- 单元测试覆盖 URL 解析和状态转换

验收：前后台切换、旋转、断网重连和连续换源 50 次无崩溃；核心错误有用户可理解的提示。

#### P2：流媒体增强

- 自定义请求头、Cookie、User-Agent 与 Referer
- Bearer / Basic 等鉴权以独立字段录入，禁止拼接到 URL
- 播放历史、收藏、最近进度、播放列表
- 字幕：内挂轨道与外挂 SRT / ASS / WebVTT，编码识别和偏移调节
- 音轨、清晰度、画面比例、手势亮度/音量/进度

验收：凭据使用 HUKS 或等价安全存储；日志和崩溃数据不含完整 URL、查询参数、Cookie 或 Authorization。

#### P3：V1 商用发布候选

- AVSession、音频焦点、中断处理、耳机和输出设备变化
- 后台音频按产品开关接入长时任务；视频退后台默认暂停
- 多窗口、折叠屏、横竖屏、深浅色与无障碍
- 冷启动、首帧、卡顿、内存与耗电指标治理
- 灰度配置、崩溃监控、埋点同意和数据保留策略
- AppTest、云测试、漏洞/隐私/兼容性/稳定性/性能测试
- APP 备案、软件著作权/主体资质、用户协议与隐私政策

验收：发布清单全部关闭；签名 APP 包通过 AGC 审核前检测；无 P0/P1 缺陷。

### V2.0：网络存储版本

- WebDAV、SMB 2/3、SFTP、FTP/FTPS、NFS 只读
- mDNS/DNS-SD、WS-Discovery、NetBIOS、SSDP、rpcbind 服务发现
- 用户主动发起的当前子网定向探测
- 服务器管理、目录浏览、凭据安全存储与连接测试
- 统一随机读取接口和稀疏缓存，接入 V1 播放内核
- 大目录、弱网、休眠恢复、断线重连与多服务器兼容测试

具体范围、技术路径和验收标准见 [NETWORK_SOURCE_PLAN.md](NETWORK_SOURCE_PLAN.md)。

## 首发功能取舍

V1 首发只包含 HTTP(S)、HLS/DASH 直链和本地文件。WebDAV、SMB、SFTP、FTP/FTPS、NFS 与网络扫描整体进入 V2。DLNA/UPnP 播放、投屏和媒体库聚合不自动并入 V2，另行评估。DRM 只通过 HarmonyOS DRM Kit 正规接入，不实现绕过或解密导出。

当前工程中的 V2 网络存储实现通过“设置 → 网络播放 → 实验性网络存储”开关显式启用，默认关闭；关闭后底栏和侧栏不显示网络存储入口，不影响 V1 的 HTTP(S) 直链播放。

## 商用品质指标

- 崩溃率：日活用户崩溃率低于 0.1%
- 播放成功率：有效且受支持资源不低于 98%
- 首帧：普通宽带下 P50 小于 1.5 秒，P95 小于 4 秒
- 卡顿：点播每小时卡顿次数 P95 小于 2
- 恢复：网络恢复后 10 秒内自动恢复或给出明确操作入口
- 隐私：零完整媒体 URL、零鉴权信息进入遥测和日志

## 需要产品方确认的事项

- 正式中文名、英文名、品牌视觉和包名
- 首发地区、收费方式、是否需要账号体系
- V2 是否与 V1 使用同一付费权益，或作为高级功能单独售卖
- NFS 首发要覆盖的服务器版本与 NAS 品牌
- 是否支持后台音频、投屏、画中画和 DRM 内容
- 隐私政策主体、客服渠道和备案主体
