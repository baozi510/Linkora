# 发布检查清单

## 账号与合规

- [ ] 开发者主体实名认证完成
- [ ] AGC 项目、APP ID、正式包名创建完成
- [ ] APP 备案、软件著作权和所需资质准备完成
- [ ] 用户协议、独立隐私政策和客服渠道可公开访问
- [ ] 首次处理个人信息前完成隐私告知与同意
- [ ] 第三方 SDK、权限、数据类型、用途和保留期逐项披露
- [ ] 用户可撤回同意、删除数据并注销账号（如有账号）

## 安全

- [ ] 发布签名私钥不进入仓库，权限和轮换制度明确
- [ ] Release 混淆开启并保存 mapping
- [ ] 凭据使用安全存储，数据库敏感字段加密
- [ ] 日志、埋点和崩溃附件完成敏感信息扫描
- [ ] TLS、证书错误、重定向和明文 HTTP 策略评审完成
- [ ] 依赖许可证与漏洞扫描通过
- [ ] 无 DRM 绕过、未授权资源聚合或侵权引导

## 功能与质量

- [ ] 有效/无效 URL、超长 URL、IPv4/IPv6、签名 URL 测试通过
- [ ] HLS、MP4、MKV、音频和字幕矩阵通过
- [ ] 弱网、断网、切网、超时、服务器错误和 Range 异常通过
- [ ] WebDAV、SMB、SFTP、FTP/FTPS、NFS 的服务器兼容矩阵通过（V2）
- [ ] 局域网扫描只在用户主动操作时运行，可取消、超时且不跨当前网段（V2）
- [ ] SMB1 被拒绝，SSH 指纹变更被阻断，TLS 证书错误默认阻断（V2）
- [ ] 明文 HTTP/FTP 与未加密共享在连接前显示风险提示（V2）
- [ ] 前后台、来电/音频焦点、锁屏、旋转和多窗口通过
- [ ] 连续换源、长时间播放和内存泄漏测试通过
- [ ] 手机、平板、折叠屏、深浅色、字体放大和读屏通过
- [ ] 冷启动、首帧、卡顿、CPU、内存、温升和耗电达标
- [ ] 自动化回归、AppTest 与云真机报告归档

## 上架物料

- [ ] 应用名称、图标、截图、视频和简介与真实功能一致
- [ ] 版本号、更新说明、分类、年龄分级和地区配置完成
- [ ] 隐私声明与应用实际行为一致
- [ ] Release APP 包签名、完整性和安装升级验证通过
- [ ] 灰度、监控、回滚和客服应急流程就绪
