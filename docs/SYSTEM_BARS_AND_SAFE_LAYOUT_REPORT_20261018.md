## 官方依据与实际布局

通过已安装可信 DevEco CLI 读取官方沉浸式布局指南与背景属性全文，而非仅依据搜索摘要：

- [开发应用沉浸式效果](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-develop-apply-immersive-effects)
- [背景设置](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-background)

官方提供窗口全屏并手动避让、组件保持安全布局并扩展背景等方案。本轮按页面用途采用两种已有平台机制，不把某种状态传递方式称为官方唯一推荐：

- 普通页使用窗口默认安全布局，移除最外层 Navigation 全局 padding。根背景、顶栏、底栏及侧栏通过 API20 的 `background(..., { ignoresLayoutSafeAreaEdges })` 仅延伸背景绘制，交互内容仍受系统安全布局约束，避免重复避让或整体缩小。
- 播放页使用全窗画布；视频保持原生“适应”比例。控制覆盖层根据系统栏、手势区和挖孔避让数据设置边距，背景与视频可到达窗口边缘。现有窗口监听更新避让值，Provider/Consumer 仅用于将这些值送到播放覆盖层。
- 当前兼容 API20、编译/目标 API26；未添加低版本兼容分支、依赖或新全屏按钮。

## 行为和错误处理

AppThemeController 统一串行提交布局、透明系统栏颜色、图标颜色及显隐。普通页随主题选择图标颜色，播放页使用浅色图标。主题刷新读取当前播放/控件策略，避免异步主题更新重新显示已隐藏系统栏。

单击视频切换控制层，同时请求系统栏显隐；离开播放恢复普通页安全布局及系统栏。播放进入 ERROR 时请求恢复控件。当前原生请求失败时恢复可见控件，并执行一次有终止错误处理的显示系统栏恢复请求；已离开的页面、旧 owner 或旧请求不覆盖新状态，不递归重试。

通过 CLI 安装、启动实际 simulator 应用，在 API26 x86_64 模拟器中固定系统播放器打开已存在的本地 120 秒 H.264/AAC 测试视频。没有新增、删除媒体或修改保存的服务器配置。

| 操作 | 观察和验收 |
| --- | --- |
| 打开普通页面 | 截图可见真实时间、电量和底部手势条；应用背景延伸至系统区域，顶栏按钮及底部 Tab 保持安全布局 |
| 打开本地视频，显示控制层 | 视频仍按适应比例显示；控制层可操作，时间、电量及底部手势条可见 |
