# 跟随系统与锁定当前方向 — 2026-10-16

## 结果与实现

按用户新要求，方向控制只保留两种状态：默认跟随系统，以及锁定当前方向。移除手动指定横屏/竖屏选项；横竖屏默认全窗口播放的布局不变，不旋转视频像素、不强制裁剪或拉伸。

基础提交：`f272f18efe1dc145df02d3939dbb99026668656d`。候选分支：`codex/linkora-player-current-direction-lock-v1`，未合入生产分支。本报告替代旧报告中关于三项方向选择的当前功能描述；旧报告保留历史实测事实。

| 状态/动作 | 实际接口与行为 |
| --- | --- |
| 进入新播放页 | `PlayerScreenDirection.FOLLOW_SYSTEM` → `window.Orientation.AUTO_ROTATION_RESTRICTED`，遵从系统旋转开关 |
| 点击“锁定当前方向” | `PlayerScreenDirection.LOCK_CURRENT` → `window.Orientation.LOCKED`；原生 SDK 直接锁定当前屏幕方向，无宽高或角度推算 |
| 锁定已确认 | 显示“已锁定当前方向”，按钮变为“解除方向锁定” |
| 点击解除 | 恢复 `FOLLOW_SYSTEM`，重新跟随当前系统方向 |
| 返回退出 | 继续串行等待、恢复进入前的方向策略与普通应用系统栏；锁定不新增全局持久化设置 |

只有原生设置完成并回读策略后才更新界面。请求未完成时按钮不可重复操作；失败保留原确认状态和错误提示。方向切换不重开视频。既有离页晚回调隔离、跨页恢复交接和连续返回保护保留。控件及资源调用点全部更新，未遗留旧横竖屏枚举引用。
